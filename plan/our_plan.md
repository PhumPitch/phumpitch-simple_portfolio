# Portfolio Website Plan: PhumPitch (Data Associate)

## 1. Visual Strategy
*   **Theme:** Modern Terminal / Dark Mode.
*   **Color Palette:**
    *   Background: `#121212` (Deep Charcoal)
    *   Text: `#E0E0E0` (Off-white)
    *   Accent: `#00FF41` (Terminal Green) or `#00A3FF` (Business Blue)
*   **Typography:** JetBrains Mono (via Google Fonts).
*   **Feel:** Professional, clean, and data-centric.

## 2. Page Structure (`index.html`)
*   **Hero Section:** 
    *   Heading: `PhumPitch`
    *   Subheading: `Data Associate`
    *   Tagline: `Bridging Technology and Business through Data.`
*   **Projects Section (Grid):**
    1.  **Project 1:** Sales Data Analysis (Python/Pandas/Matplotlib)
    2.  **Project 2:** Business Intelligence Dashboard (SQL/PowerBI/Tableau)
    3.  **Project 3:** Automated ETL Pipeline (Python/API Integration)
*   **Contact Section:**
    *   Email, LinkedIn, GitHub.

## 3. Technical Implementation
*   **HTML5/CSS3:** Vanilla implementation for maximum speed and compatibility.
*   **Responsive Design:** Mobile-first approach using CSS Flexbox/Grid.
*   **Deployment:** GitHub Pages (Root directory of the `main` branch).

## 4. Execution Roadmap
1.  **Step 1:** Create `index.html` and `style.css` in the project root.
2.  **Step 2:** Verify responsiveness and visual aesthetic.
3.  **Step 3:** Initialize Git repository (`git init`).
4.  **Step 4:** Push to GitHub and enable GitHub Pages in settings.
