# PhumPitch Portfolio

A modern, terminal-themed portfolio website designed for a **Junior Data Associate**. 

## 🚀 Live Demo
The site is hosted on GitHub Pages: [PhumPitch Portfolio](https://phumpitch.github.io/phumpitch-simple_portfolio/)

## 🛠️ Tech Stack
- **HTML5**: Semantic structure.
- **CSS3**: Custom styling with a modern dark mode/terminal aesthetic.
- **Typography**: [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) for that developer-centric feel.

## 📂 Project Structure
- `docs/`: Contains the production-ready code (GitHub Pages source).
  - `index.html`: The main landing page.
  - `style.css`: Custom styles and responsive layout.
- `plan/`: Architectural decisions and project roadmap.
